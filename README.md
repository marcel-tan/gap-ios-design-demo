# Gap iOS Design Demo

Design-first replica of the [Gap iOS app](https://apps.apple.com/us/app/gap-apparel-denim-and-more/id326347260), built as a demo of a **PRD → wireframes → Figma → SwiftUI** delivery process. Scoped to one golden path: ordering a fall outfit (cardigan, '90s loose jeans, denim jacket) for in-store pickup.

| Artifact | Where |
|---|---|
| PRD + user stories | [`docs/PRD.md`](docs/PRD.md) |
| Wireframe spec | [`docs/wireframes.md`](docs/wireframes.md) |
| Figma file (wireframes, foundations, components, hi-fi screens, prototype) | https://www.figma.com/design/2amCWqHqUoNvHtOQUxtd7I |
| Figma node ↔ Swift view registry | [`docs/figma-nodes.md`](docs/figma-nodes.md) |
| Brand assets | [`design/brand/`](design/brand/) (official Gap wordmark, app icon) |
| App Store reference shots | [`design/reference/`](design/reference/) |

## App

SwiftUI · iOS 17+ · Observation · MapKit · Kingfisher · XcodeGen. See `DEMO.md` (added with the app) for build/run instructions.
